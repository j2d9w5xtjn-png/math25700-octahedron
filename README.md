# Octahedron Rotations

Interactive rotations of the regular octahedron: the 24 rotations permute the four pairs of opposite faces, giving all of S4, and permute the three vertex axes, giving a map onto S3 with kernel V (Math 25700).

Live page: https://j2d9w5xtjn-png.github.io/math25700-octahedron/

`index.html` is a built copy; the source and tests are kept elsewhere.
